Job ApplyMate 是一款适用于 Chrome 和 Edge 的求职申请搭档，用于集中管理求职资料、识别招聘表单并快速填入个人信息、教育经历、实习项目和简历文件。

## 功能说明

| 功能 | 说明 |
|---|---|
| 资料管理 | 保存基本信息、教育经历、实习经历、项目经历、技能、证书和自定义信息 |
| 快速填充 | 从插件弹窗启动，自动识别当前网页的招聘表单字段并填入资料 |
| 逻辑表单识别 | 将“是/否”单选组、复选组、日期拆分控件和重复经历行作为完整问题处理，避免逐个选项误报 |
| 智能日期适配 | 自动适配网站要求的年份、月份和日期格式，例如将 `2020.06`、`2020.6`、`2020-06` 视为同一月份 |
| 增强下拉框填写 | 支持常见组件库、动态加载、搜索下拉、多选与级联选择；填写后回读验证，避免“是/否”和“全日制/非全日制”误选 |
| 失败复盘与学习 | 填充完成后列出失败字段；可以修正并记住，也可以逐项或全部跳过本次，下次访问同一网站时优先使用学习结果 |
| AI 扫描填充 | 按表单块一次识别整页空白字段，将同一教育、实习或项目块绑定到同一条资料后批量填入（需配置 AI） |
| AI 框选补填 | 框选表单模块或自定义区域，只对其中空白字段执行 AI 匹配与填入（需配置可识别图像的 AI） |
| 信息浮窗 | 直接固定在招聘网页内，可拖动并记住位置；先聚焦网页输入框，再点击单条资料完成写入，失败时自动复制 |
| 多简历库 | 保存多份面向不同岗位的简历；保留原文件名，并用插件内分类区分；每次填写可选择指定简历或不上传 |
| 简历解析 | 支持 PDF、DOCX、Markdown、TXT 和结构化 JSON |
| 投递记录管理 | 新建、查看、筛选、排序、整行编辑、删除，并支持 CSV 导入导出 |
| JSON 备份 | 版本化导入、导出，导入前验证格式并显示摘要 |
| WebDAV 同步 | 保存后自动同步，使用 ETag 防止跨设备静默覆盖 |

## 快速安装

### 普通用户安装

如果你只是想使用插件：

1. 点击当前仓库右侧的 Releases 页面下载最新版，或直接下载仓库中的 [`release/job-applymate-extension.zip`](release/job-applymate-extension.zip)。
2. 先将压缩包解压到本地任意文件夹。
3. 打开 Chrome 或 Edge 的扩展程序管理界面。
4. 开启页面内的“开发者模式”。
5. 点击“加载解压缩的扩展”。
6. 选择刚才解压出来的扩展目录。
7. 将“Job ApplyMate”固定到浏览器工具栏，方便使用。

浏览器不能直接加载 `.zip` 压缩包，必须先解压，再加载解压后的目录。

## 如何使用

### 配置个人资料

1. 点击浏览器工具栏中的插件图标。
2. 点击“设置个人信息”进入设置页。
3. 依次填写基本信息、教育经历、实习与项目、自定义信息。
4. 点击页面底部“保存”，右上角出现“保存成功”后即可关闭页面。

AI 配置不是必需项。未配置 AI 时，基本信息管理、JSON 简历导入、信息浮窗、复制和常规表单填充仍可使用。

### 导入简历

在“简历库”中添加文件：

- JSON、PDF、DOCX、Markdown、TXT：支持本地基础解析；配置 AI 后可获得更完整的结构化识别。
- 添加前可填写“产品岗”“运营岗”等分类。分类只在插件里显示，上传到招聘网站时仍使用文件的原始名称。
- 可重复添加多份简历，并在列表中修改分类或删除文件。

解析后的资料会显示在设置页中，确认内容后点击保存。

### 填写网申表单

1. 打开招聘网站的申请或简历填写页面。
2. 点击浏览器工具栏中的插件图标。
3. 在“本次简历”中选择“不自动上传简历”或一份已分类的简历。
4. 在插件弹窗中点击“快速填充”。
5. 插件识别当前页面字段并填入已保存的信息；只有本次明确选择的简历会被上传。
6. 填充结束后，页面右下角会列出未能自动填写的字段。
7. 输入网站接受的正确内容并点击“填写并记住”，下次访问同一网站时会优先使用该记录。
8. 暂时不想处理时，可对单项选择“本次不填”，或选择“本次全部不填”。
9. 自动填充后请人工核对内容，尤其是日期、单选项、下拉选项和简历文件名。

如果某个字段没有正确识别，可打开“信息浮窗”，单独复制或填入基本信息、教育经历、实习经历、项目经历和自定义信息。

### AI 扫描填充

AI 扫描填充比快速填充的准确性更高，使用前需要先在“AI 设置”中配置可用的模型服务。

1. 打开需要填写的网申页面。
2. 点击浏览器工具栏中的插件图标。
3. 在“本次简历”中选择不上传或指定一份简历。
4. 在弹窗中点击“AI 扫描填充”。
5. 插件先使用本地规则和学习记录填写能确定的内容，只有剩余空白字段才会请求 AI。
6. AI 按字段逐项识别，每返回一项就立即写入并验证；相同网站、资料和字段可复用已验证缓存。
7. 页面右下角会实时显示当前字段和完成数量。单个 AI 请求超过 25 秒会停止后续请求，避免长期卡住。
8. 如果扫描过程中需要停止，可点击页面提示中的“终止”按钮；已经成功填入网页的内容会保留，不会回滚。

AI 扫描填充不会覆盖已经有值的输入框。模型返回的普通文本必须能在已保存资料中找到，选项值也必须能安全匹配网站提供的实际选项；无法确认的字段会留给失败复盘。简历文件、简历原文和内部记录 ID 不会随页面扫描请求发送。完成后仍建议人工复核。

### 使用信息浮窗

信息浮窗适合逐个处理自动填充未识别的特殊字段。写入操作必须按以下顺序完成：

1. 保持网申页面打开，点击浏览器工具栏中的插件图标。
2. 点击“打开信息浮窗”，资料面板会直接固定在当前招聘网页右侧；可拖动顶部调整位置，插件会记住位置。
3. 在同一网页中先点击需要填写的输入框、文本域或下拉框，使光标停留在该字段中。
4. 在固定浮窗中展开对应的教育、实习、项目或自定义信息。
5. 点击具体字段或整条自定义信息，例如“学校”“专业”“公司”“岗位”，插件会把该字段值写入刚才聚焦的网页输入框。
6. 浮窗滚动页面时仍保持固定；若被网站重绘误删会自动恢复。页面不允许直接写入时，内容会自动复制到剪贴板，可手动粘贴。



### AI 框选补填

AI 框选补填用于处理整页填充后仍为空白、命名复杂或重复出现的字段。与“AI 扫描填充”相比，它会结合图像判断填充内容。使用前需要先在“AI 设置”中配置可识别图片的模型服务。

1. 打开需要补填的网申页面。
2. 点击浏览器工具栏中的插件图标。
3. 点击“AI 框选补填”，插件弹窗会关闭，网页进入区域选择状态。
4. 将鼠标移动到“基本信息”“教育经历”“实习经历”或“项目经历”等表单模块上，紫色边框会显示当前识别区域。
5. 单击整个模块，或按住鼠标拖出一个自定义矩形区域。
6. 插件只收集选中区域内仍为空白的字段，结合已保存资料交给 AI 匹配并填入。
7. 页面右下角会显示扫描、匹配和填入进度；需要停止时点击“终止”，按 `Esc` 可在选择区域时取消。

AI 框选补填不会覆盖已经有值的输入框。完成后仍需人工检查日期顺序、下拉选项和生成内容。

### 管理投递记录

投递记录用于集中管理已经投过或准备投递的岗位信息，包括公司名称、岗位名、来源站点、职位链接、投递状态、投递日期、工作地点和备注。

新建投递记录有两种入口：

1. 点击浏览器工具栏中的插件图标。
2. 在弹窗右上角点击“新建投递记录”，进入独立的新建页面。
3. 如果当前网页是岗位详情页，插件会优先根据当前页面生成一份草稿，自动带入公司、来源站点或职位链接等信息；如果无法识别，也可以手动填写。
4. 默认投递状态为“已投递”，可改为“待投递”“已笔试”“面试中”“offer”或“终止”。
5. 点击“保存投递记录”后，页面会保留“已保存”状态，方便继续确认内容。

查看和管理已有投递记录：

1. 点击插件弹窗右上角“打开投递记录”，或进入设置页中的“投递记录”页面。
2. 列表支持按公司、岗位、链接、状态、日期、地点等列排序。
3. 点击“筛选”可按公司、岗位、状态、地点等条件缩小范围，点击“清空筛选”可恢复全部结果。
4. 浏览态下，职位链接会显示为可点击的超链接。
5. 点击某一行右侧的编辑按钮后，该行会直接切换为整行编辑状态；修改后点击“保存”即可更新，点击“取消”可放弃本次修改。
6. 点击删除按钮可删除该条记录，删除前会弹出确认提示。

批量迁移或备份投递记录时，可使用列表右上角的 CSV 工具：

- “导出 CSV”：导出当前全部投递记录，方便在表格软件中查看、整理或另存。
- “导入 CSV”：导入以前导出的记录，适合迁移旧数据或批量补录。导入时会尽量保留合法记录，并对状态值不规范或重复项给出提示。

投递记录不会写入“导出完整数据”的 JSON 备份中；如需单独备份或迁移投递记录，请使用 CSV 导入导出功能。

### 备份与同步

设置页的“数据与同步”提供两种备份方式，手动导入导出或使用 WebDAV 自动同步。手动导入导出时不包含投递记录；使用WebDAV 同步时，会包含投递记录。

- “导入完整数据”：选择以前导出的 JSON，检查通过后确认覆盖本地资料。
- “导出完整数据”：下载当前全部资料的 JSON 备份。

完整备份包含个人资料、简历原文件、AI 配置和 API Key，以及 WebDAV 同步设置（服务器地址、用户名、密码）。字段匹配缓存和同步状态不会写入备份文件。

## WebDAV 配置

在“数据与同步”中填写：

- WebDAV 服务器地址
- 用户名
- 密码或第三方应用密码

首次点击“测试连接”时，插件会创建或确认远端目录：

为保证旧版导出的 JSON 和已有 WebDAV 备份可以继续直接使用，远端目录名保持兼容：

```text
job-application-helper/
└── job-application-helper.json
```

保存同步设置后，点击“立即同步”完成首次上传。启用自动同步后，保存个人资料、解析简历、保存 AI 配置、导入完整备份、更改投递记录都会排队同步。

同步规则：

- 只有本地变化：上传本地版本。
- 只有远端变化：下载远端版本。
- 两端都变化：停止覆盖并显示冲突选择。
- 同步失败：保留已成功保存的本地数据。

坚果云通常使用：

```text
服务器地址：https://dav.jianguoyun.com/dav/
用户名：坚果云登录邮箱
密码：第三方应用管理中生成的应用密码
```

如果返回 401，请检查账号和应用密码；如果返回 403、404 或 409，请确认地址是可写的 WebDAV 根目录，而不是普通网页或分享链接。

## 安装与开发
### 开发与本地构建

如果你需要自行修改代码、重新构建，才需要准备下面的环境：

- Chrome 或 Edge 116 及以上版本
- Node.js 20.19 及以上，或 Node.js 22.12 及以上
- npm

推荐安装最新的 Node.js LTS 版本。

### 一键安装并构建

下载项目后，在项目根目录运行对应脚本：

- macOS：双击 `一键安装依赖.command`
- Windows：双击 `一键安装依赖.bat`

脚本会依次完成：

1. 检查 Node.js 和 npm。
2. 使用 `npm ci` 安装锁定版本的依赖。
3. 运行全部自动化测试。
4. 构建可加载的 `dist/` 目录。


### 常用命令

```bash
npm test
npm run build
npm run lint
npm run dev
```

- `npm test`：运行备份格式与 WebDAV 同步测试。
- `npm run build`：类型检查并生成 `dist/`。
- `npm run lint`：运行静态代码检查。
- `npm run dev`：启动 Vite 开发服务，扩展调试仍需构建后加载 `dist/`。

## 数据说明

- 默认数据保存在浏览器扩展的 `chrome.storage.local`。
- JSON 导入文件上限为 20 MiB。
- 手动备份和 WebDAV 文件为明文 JSON，可能包含个人信息、简历和 AI API Key。
- 只有主动配置并启用 WebDAV 后，数据才会上传到用户自己的 WebDAV 服务。
- 卸载扩展或清除扩展数据前，建议先导出完整备份。
